# WireGuard Manager (wg-manager)

一个专为 Ubuntu 系统设计的轻量级、开箱即用的 WireGuard 命令行管理脚本库。支持通过 curl 一键安装，支持多设备灵活添加、终端二维码扫码、配置文件导入以及精准点对点删除。

---

## 🚀 特性

- **一键远程安装**：复制单行命令即可完成服务端初始化并自动注册全局管理命令。
- **多设备支持**：允许同时添加多台设备（不限制手机或电脑），系统会自动分配不冲突的内网 IP (10.0.0.x)。
- **全局命令**：安装后可在终端任意路径直接执行 wg-add、wg-list、wg-remove。
- **精准删除管理**：支持根据设备名称进行精准吊销，被删除的设备会立即断开连接，且绝不影响其他设备。
- **热重载生效**：增减设备无需重启 WireGuard 服务，零中断即时生效。

---

## 📦 一键安装与部署

在您的 Ubuntu 服务器上（推荐 Ubuntu 20.04 / 22.04 / 24.04），以 **Root 权限** 执行以下一键安装命令：

curl -fsSL [https://raw.githubusercontent.com/messi1991/wireguard-manager/main/install.sh](https://raw.githubusercontent.com/messi1991/wireguard-manager/main/install.sh) | bash

*脚本会自动检测默认网卡、公网 IP、安装必要依赖，并自动配置好全局命令。*

---

## 🛠️ 详细使用指南

所有命令均需使用 **Root 权限** (`sudo`) 运行。

### 1. 添加设备（支持手机、电脑、平板等任意设备）
你可以通过参数自定义任何容易识别的设备名称：

- **命令示例**：
  sudo wg-add iphone
  sudo wg-add macbook
  sudo wg-add windows-pc
  *(注：脚本对名称没有硬性限制，你想怎么命名都可以)*

- **如何使用生成的内容**：
  无论添加什么设备，脚本都会同时做两件事：在终端打印**二维码**，并在服务器 `/etc/wireguard/clients/` 目录下生成同名的 `.conf` 文件。
  - **手机端**：直接打开手机 WireGuard App 扫描终端生成的二维码即可秒级导入。
  - **电脑端**：忽略终端的二维码，直接去服务器 `/etc/wireguard/clients/<设备名>.conf` 路径下获取配置文件，下载到本地电脑并在电脑版客户端中导入即可。

- **交互式添加**：
  如果不带参数直接运行 `sudo wg-add`，脚本会提示你手动输入设备名称。

---

### 2. 查看所有已注册设备与内网 IP
若你想核对当前添加了哪些设备以及它们的内网 IP 分配情况，可执行：

sudo wg-list

---

### 3. 精准删除指定设备（吊销权限）
当某台设备丢失或不再需要访问时，可以通过设备名称进行**精准删除**。

- **直接带参数删除（推荐）**：
  sudo wg-remove macbook
- **交互式删除**：
  sudo wg-remove
  输入名称并二次确认后，该设备会立刻被踢出网络并永久吊销权限，其他正在使用的设备完全不受影响。
